# explainviz

[English](README.md) | 简体中文

[![skills.sh](https://skills.sh/b/liujy20/explainviz)](https://skills.sh/liujy20/explainviz)

**把文字解释变成图解、图表和可交互的可视化。**

`explainviz` 是一个 Agent Skill，帮助 AI 助手根据你的问题选择合适的可视化方式。你可以用它理解系统流程、比较数据、探索几何关系，或尝试界面设计。只需描述你想弄懂什么，skill 就会指导助手选择并制作相应的图示。

## 能做什么

| 使用场景 | 可以生成的内容 |
| --- | --- |
| 理解流程和系统 | Mermaid 流程图、时序图、状态图、实体关系图 |
| 比较数据与变化趋势 | 数据图表、时间线、并列对比图、交互式比较 |
| 观察地理分布 | 带数据、标签和区域选择的地图 |
| 理解几何与拓扑 | 平面图解、多边形运算、可旋转的三维曲线与曲面 |
| 探索参数对结果的影响 | 带滑块、选项和联动更新的交互式解释 |
| 尝试界面设计 | 可点击的页面、组件和设计变体 HTML 预览 |

它也可以解释或修复 Mermaid 图，并根据相关源码或设计说明生成图示及配套解释。

## 安装

在已安装 Node.js 和 npm 的终端中运行：

```bash
npx skills add liujy20/explainviz
```

按安装提示选择使用的 AI 助手和安装范围。本技能采用通用的 Agent Skills 格式，skills CLI 支持 Codex、Claude Code、Cursor 等工具。技能发现和预览方式取决于你使用的工具。

## 如何使用

安装后，在对话中明确让助手使用 `explainviz`，再描述你的问题即可。无需提前指定绘图库或图表类型。

**解释一个流程**

```text
使用 explainviz 解释订单从支付到发货的流程。
包含支付失败和取消订单的情况，并标明状态变化。
```

**比较一组数据**

```text
使用 explainviz 比较下面的月度销售额：
产品 A：12、18、15、24；产品 B：10、14、20、22（1—4 月，单位：万元）。
同时展示两条趋势，并让每个月的精确数值清晰可读。
```

**探索三维形状**

```text
使用 explainviz 解释马鞍面 z = (x² − y²) / 4。
让我可以旋转模型、开关坐标网格，并切换 XY、XZ、YZ 视角。
```

**尝试一个界面**

```text
使用 explainviz 做一个任务列表的界面预览。
让我可以筛选已完成任务，并切换列表与网格布局。
```

提问时附上相关数据、公式、源文件或设计约束。你也可以指定静态图片或交互式 HTML、语言和主题，并在同一对话中继续调整结果。

## 你会得到什么

- **静态关系图：**可用于 Markdown 和文档的 Mermaid 源码。
- **静态可视化解释：**渲染后的图片，同时保留可编辑的 HTML 源文件。
- **交互式解释与原型：**HTML 文件或当前工具支持的内嵌预览，以及初始状态预览图。
- **配套说明：**图示的关键结论、假设与适用边界。

独立 HTML 可以在浏览器中打开，也可以继续编辑。通过 CDN 加载绘图库的文件需要联网，三维视图还需要浏览器支持 WebGL。内嵌展示、截图和浏览器验证取决于 AI 助手可用的工具；skill 要求助手说明未能完成的检查。

## 适用范围

当图示或交互能帮助你理解问题时，可以使用 `explainviz`。普通表格、生产环境 UI 开发和科学出版级图表不属于它的主要用途。几何图示用于辅助推理，不能代替数学证明。
