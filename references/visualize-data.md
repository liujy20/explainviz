# 数据图、地图与比较

只加载当前需要的模式。先选能回答问题的视觉编码，避免 KPI 卡片、无关筛选器和重复视图。

## 数值与统计图

- 数据丰富的笛卡尔或统计图用 D3 7.9.0：`https://cdn.jsdelivr.net/npm/d3@7.9.0/dist/d3.min.js`。简单直接标值可手写 SVG。
- 每个子图独立响应式 SVG，ResizeObserver 重绘；预留至少 64px 的 y 轴空间。轴显示量与单位，关键点直接标值。
- 域根据全部观测、不确定区间和参考线计算，保留边距；不猜坐标范围。散点半径与线端不超出绘图区，用 clipPath 控制。
- 图直接置于透明背景，只有绘图区细框，不套卡片。线、标记与图例共享系列色；文本保持前景色。密集不确定性用带状区域，稀疏用误差棒。
- 多序列悬停用一条覆盖层和一个共享提示框，按指针 x 在每个可见系列插值，显示同一 x 的比较；用 `d3.bisector(d => d.x).center(values, x)` 找邻点。触屏可固定选中位置。系列开关同时切换线、标记和提示行。
- 孤立数据点命中区域至少约 32px，触屏 44px；密集散点用最近点覆盖层。SVG 标记可使用 data-tooltip，绘图库已有图例与提示行为则复用。
- 变化时插值图形而非仅淡入淡出。缩窄后重算刻度，360px 通常最多四个 x 刻度；标签保持至少 11px 且互不遮挡。

## 地图

- 使用有来源的 GeoJSON/TopoJSON 与经纬度，并用 d3-geo 投影；不凭记忆描地理轮廓。用户只要示意关系时才画明确标注的示意地图。
- 世界图可用 `https://esm.sh/@d3-maps/atlas@1.0.0/world/countries/countries-110m`，配 topojson-client 3.1.0 的 `feature(world, world.objects.features).features`；ISO3 对应 feature.properties.id。
- 美国州县可用 `https://cdn.jsdelivr.net/npm/us-atlas@3/counties-10m.json/+esm`。城市、邮区和街区找公开权威边界，不猜相邻资源 URL。
- 代理在生成前读取并校验边界与数据，再嵌入 fragment；浏览器 fragment 不发网络数据请求。局部点位需显示适当城市/街区上下文，不用空白底板冒充地图。
- 地图占主视图，仅保留必要图例和一个选中项摘要。交付前检查投影、标签、连接字段及实际加载结果。

## 时间、分类与份额

- 排期或并行流程：共用时间轴的对齐泳道，标出资源、阶段、等待和瓶颈，不用无时间比例的方框暗示时长。
- 多指标或分布比较：共用尺度的小多图，所有要求的维度同时可见，不藏到切换按钮后。
- 密集分类：一项摘要、每格一个可读标识、一份小图例，其他属性放可访问标签或选中摘要；默认只允许选择。
- 份额或时间分配：每期一个堆叠图，显示类别组成；不能只画总量，也不重复加同数据热力图。
