# 几何与拓扑图解

用于相交、包含、孔洞、有向边、面邻接、扫描线、多边形运算、坐标几何和二维反例。纯符号推导不启动，一般软件依赖图走结构分支。

## 执行

1. 确定图要证明或反驳的关系。简单问题用单面板；对比局部与全局、正确与错误时才用两三个面板。
2. 使用 [几何 HTML 节点](../assets/examples/geometry-node.html) 的 HTML + D3 模板表达坐标、图层、箭头和标签；不使用 JSON 驱动的 Python 绘图库。
3. 保存自包含 HTML 到任务目录，先在浏览器打开并检查渲染，再用浏览器截图能力显示结果。二维几何底层使用固定版本的 D3 scales/paths；需要布尔几何时使用 `polygon-clipping`。
4. 检查标签、方向、裁切和遮挡；修正后展示截图，并解释结论和边界。不能查看图片时明确说明未做视觉检查。

## 几何约束

- 默认 x 向右、y 向上、等比例；屏幕坐标等其他约定须说明。概念拓扑图隐藏坐标轴，坐标值或扫描线重要时保留。
- 中文对话使用中文标签；从本机已安装字体中选支持中文的字体。不能假设安装了 macOS 字体。
- 标注顶点、交点、端点和代表点。半透明扇区区分面，有向箭头表示遍历；颜色同时配合文字或线型。
- 多边形并集用 `polygon-clipping` 计算；孔洞用真实内环和 even-odd 填充，不用背景色遮挡伪造。
- 反例同时呈现局部选择及其导致的全局错误，图示不能替代推导。
- 输出写入任务 outputs/，不要写入 skill 安装目录；支持图片嵌入的宿主用绝对路径展示，否则交付文件。

## 稳定表现与依赖

- 当前面/左侧面用蓝色，另一面/孔洞橙色，正确边或有效区间绿色，错误边/交点红色，墙体灰色，扫描线与反向射线灰色虚线。使用相同语义配色和直接标签。
- 绘图使用浏览器 HTML + D3 7.9.0 和 `polygon-clipping` 0.15.7；通过 esm.sh 固定版本导入，不要求预装 Python 或 Node。
- 中文标签选择本机支持中文的字体，通过数据中的 font_sans_serif 指定；坐标与颜色基线保持不变，只有语言/主题要求才调整。
