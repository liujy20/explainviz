# 几何与拓扑图解

用于平面几何、曲面、空间曲线、纽结链环和拓扑反例。纯符号推导不启动，一般软件依赖图走结构分支。

## 执行

1. 确定对象、与结论有关的假设及推理。简单问题用单面板；对比局部与全局、正确与错误时才用两三个面板。
2. 平面坐标关系使用 [HTML + D3 模板](../assets/examples/geometry-node.html)；需要旋转辨认的曲面、空间曲线和链环使用 [Three.js 模板](../assets/examples/geometry-3d-node.html)。纯符号或抽象拓扑关系不强制使用三维。遵循[交付规则](visualize.md)选择静态截图或交互文件。
3. 保存 HTML 到任务目录，先在浏览器检查渲染。二维几何底层使用固定版本的 D3 scales/paths；需要布尔几何时使用 `polygon-clipping`。数据内嵌不等于远程库可离线使用。
4. 检查标签、方向、裁切和遮挡；修正后展示截图，并解释结论和边界。不能查看图片时明确说明未做视觉检查。

## 几何约束

- 默认 x 向右、y 向上、等比例；屏幕坐标等其他约定须说明。概念拓扑图隐藏坐标轴，坐标值或扫描线重要时保留。
- 函数或数据图可为读取而独立缩放各轴，但须显示刻度、单位并注明非等比例，不能据画面角度或长度推导几何性质。
- 中文对话使用中文标签；从本机已安装字体中选支持中文的字体。不能假设安装了 macOS 字体。
- 标注顶点、交点、端点和代表点。半透明扇区区分面，有向箭头表示遍历；颜色同时配合文字或线型。
- 多边形并集用 `polygon-clipping` 计算；孔洞用真实内环和 even-odd 填充，不用背景色遮挡伪造。
- 反例同时呈现局部选择及其导致的全局错误，图示不能替代推导。
- 输出写入任务 outputs/，不要写入 skill 安装目录；支持图片嵌入的宿主用绝对路径展示，否则交付文件。

## 三维坐标与操作

- 当坐标、方向、投影或变换有助理解时，使用可开关的 MATLAB 风格坐标框：淡灰底面和后壁网格、小字号轴名及适量刻度。网格与模型单位一致，默认等比例；比较模型共用尺度，说明局部/世界坐标及排版平移。坐标无助于问题时可默认隐藏。
- 提供旋转、缩放和复位；投影比较需要时增加 XY/XZ/YZ 标准视角，手动旋转后切回自由视角状态。镜像须区分模型坐标映射与相机变化。避免突出的大号 XYZ 或独立彩色箭头。
- 桌面与窄屏均应完整呈现模型及关键标签；用模型边界拟合相机，不只检查对象与视锥相交。验证 canvas 像素非空、实际旋转、网格开关和标准视角，并查看截图；像素非空不证明几何正确或可读。

## 推理、边界与库语义

- 在图外给出推理或定理依据，区分等比例模型、夸张示意、有限采样、数值近似及标准结果引用。截图或动画不证明一般命题，引用不变量不等于程序已计算该不变量。说明采样范围及近似；未评估误差时不宣称严格精度保证。
- 按问题区分嵌入/浸入/投影、内在/外在、局部/全局、有限阶段/无限极限；极限性质与不可嵌入结论需要图外依据。
- 覆盖相关的空集、点、线、正面积、临界值及两侧。数学零、很小的正数和像素不可辨认分别处理；说明容差含义，不能无说明地用 epsilon 改变维度或拓扑。
- 核对库在共线、共圆、重复点、自交及零面积输入下的实际返回值，说明填充、含边界及正则化约定。API 的 null、数组长度或 MultiPolygon 条目数不能直接认定数学空集、维度或连通分量数。

## 稳定表现与依赖

- 当前面/左侧面用蓝色，另一面/孔洞橙色，正确边或有效区间绿色，错误边/交点红色，墙体灰色，扫描线与反向射线灰色虚线。使用相同语义配色和直接标签。
- 绘图使用浏览器 HTML + D3 7.9.0、`polygon-clipping` 0.15.7 或 Three.js 0.180.0；Three.js 与 OrbitControls 必须同版本。不要求用户预装 Python 或 Node。
- 中文标签通过 CSS font-family 或 canvas 字体选择本机支持中文的字体；坐标与颜色基线保持不变，只有语言/主题要求才调整。
